## Story

```text
As the AI Project Manager,
I want key assistant interactions logged,
so that I can report whether the pilot saves agent time without increasing
answer risk.
```

## Notes

- **Notes:** Proposed by the agent and accepted by the PM. It covers the scenario constraint
  "evidence that the pilot saves time without increasing answer risk". **The
  agent doesn't assume any baseline data exists.** The team must agree on how
  the baseline will be measured.
- **Open questions:** [OQ-7] success measures and baseline method.
- **Assumptions:** [A-12], [A-13].

## Acceptance criteria

- **AC-09.1** These events are logged: question asked, answer shown, "no
  approved source" fallback shown, source reference clicked, source open
  failed, answer flagged (with reason), flag approved, quick-copy used, and
  issue reported.
- **AC-09.2** Each event records a timestamp, answer ID, and an agent
  identifier in the form approved by privacy review **[A-12]**.
- **AC-09.3** Customer personal data is not stored in the event log beyond
  what the privacy review approves **[TBD]**.
- **AC-09.4** The AI PM can export a weekly summary covering the flag rate,
  fallback rate, source-click rate, and issue reports.
- **AC-09.5** The success measures and the baseline method are written down
  and agreed by the end of pilot week 1 **[OQ-7]**. The agent doesn't define
  them.

## Assumptions needing validation

- **A-12** Logging agent interactions is allowed under internal privacy or employee-monitoring policy. _(validate with: Privacy / HR / works council (if applicable))_
- **A-13** A time baseline can be measured. No existing baseline data is assumed. _(validate with: AI PM / support team lead)_
