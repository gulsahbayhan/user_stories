## Story

```text
As a support agent,
I want each AI answer to show the title and section of the approved policy
document(s) it is based on,
so that I can verify the source before replying to a customer.
```

## Notes

- **Notes:** The team decided that this story owns the **"no approved source
  found" fallback**, so PA-04 does not duplicate it. The deep link was split
  out into PA-02.
- **Decisions:** [OQ-1] list every contributing document; [OQ-2] hide the
  generated answer when no approved source is found. Both decided by the PM.
- **Assumptions:** [A-1], [A-14].

## Acceptance criteria

- **AC-01.1** Given an answer generated from one approved document, the answer
  shows that document's **title** and **section heading**. If the document has
  no section headings, it shows the page number instead.
- **AC-01.2** Given an answer generated from more than one approved document,
  **every** contributing document is listed with its title and section.
  *[OQ-1: decided]*
- **AC-01.3** The source reference appears directly with the answer. The agent
  doesn't need any extra click to see it.
- **AC-01.4** Given a question for which no approved source is retrieved, **no
  generated answer text is shown**. Instead, the agent sees "No approved
  source found" and the standard escalation guidance. *[OQ-2: decided;
  this story owns the fallback]*
- **AC-01.5** On the agreed pilot test set of **[TBD]** questions, every
  displayed reference matches the document and section that were actually
  retrieved for that answer.

## Assumptions needing validation

- **A-1** All approved policy documents in the pilot set are digitized and indexed with section metadata. _(validate with: Policy content owner / engineering)_
- **A-14** Agents will check sources before replying. This is a behavior assumption, not established evidence. _(validate with: Pilot observation (PA-09 click data))_

## Open questions

- **OQ-1** What happens if an answer relies on multiple policy documents? → ✅ **Decided:** list every contributing document.
- **OQ-2** When no approved source is found, should the answer be hidden or shown with a warning label? → ✅ **Decided:** hide the generated answer and show a "No approved source found" message.
