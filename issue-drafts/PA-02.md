## Story

```text
As a support agent,
I want to click a source reference and land on the cited section of the
approved document,
so that I can check the exact wording without searching for it.
```

## Notes

- **Notes:** Split out of the original Story 1 so that PA-01 can ship even if
  section anchors aren't available for every document.
- **Assumptions:** [A-3], [A-4].

## Acceptance criteria

- **AC-02.1** Clicking a source reference opens the document in a new tab or
  side panel. The agent's current support case stays open.
- **AC-02.2** If the document supports section anchors, it opens at the cited
  section. If it doesn't, it opens at the start and the cited section name is
  shown. *[A-4]*
- **AC-02.3** The link opens the **same approved version** that was cited, not
  a newer draft or a retired version.
- **AC-02.4** If the document can't be opened (missing, moved, or no access),
  the agent sees "Source could not be opened", the reference text stays
  visible, and the failure is logged (PA-09).

## Assumptions needing validation

- **A-3** Pilot agents already have read access to the system that stores the source documents. _(validate with: IT / access management)_
- **A-4** Source documents support section-level deep links (anchors) for at least some formats. _(validate with: Engineering)_
