## Story

```text
As a support agent,
I want AI answers below the agreed confidence threshold to show a
"Requires Human Review" warning,
so that I know not to send them to a customer without checking.
```

## Notes

- **Notes:** This story only warns. It doesn't block quick-copy. The pilot
  measures the flag rate before deciding whether blocking (PA-06) is worth the
  friction.
- **Open questions:** [OQ-3] threshold value.
- **Assumptions:** [A-5], [A-15].

## Acceptance criteria

- **AC-04.1** Given an answer with a confidence score below the threshold
  **[TBD, OQ-3]**, a "Requires Human Review" badge is shown next to the
  answer.
- **AC-04.2** Given an answer at or above the threshold, no badge is shown.
- **AC-04.3** The badge includes a text label and the reason ("Low
  confidence"). It doesn't rely on color alone.
- **AC-04.4** An authorized admin can change the threshold in configuration
  without a code release.
- **AC-04.5** Every time an answer is flagged, the event is logged with the
  answer ID, score, and reason (PA-09).
- **AC-04.6** This story doesn't block any agent action. Blocking belongs to
  PA-06.

## Assumptions needing validation

- **A-5** The retrieval or model pipeline produces a confidence score reliable enough to set a threshold on. _(validate with: Engineering / ML)_
- **A-15** The flag rate will be low enough that agents aren't slowed down more than the pilot gains. _(validate with: Pilot data (PA-09))_
